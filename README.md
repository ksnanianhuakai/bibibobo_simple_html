# 哔哔啵啵 · 单文件版

把一句话变成「哔哔啵啵」的小人说话声。一个 HTML 文件，双击就能用，不联网、无依赖。

## 用法

双击 `index.html`，输入一句话，选声线（大肥鱼 / 路墨），点「说！」。也可以点「下载 WAV」导出音频文件。

## 原理

1. 一条抗混叠锯齿波（polyBLEP）
2. 两个带通滤波器捏出口型（每种口型 = 两个共振峰频率）
3. 一个汉字一声，用哈希定音高和口型（同一个字永远同一声）
4. 每个角色一组音阶
5. 标点管语气：`?` 尾音上滑，`!` 整句升高，`……` 整句压低并下滑

## 改动（相对原版）

- 合并为单文件 HTML，不依赖任何外部文件
- 语法降级为 ES5，兼容旧版浏览器 / 微信内置浏览器
- 播放改为三层兜底：Web Audio → `<audio>` + Blob URL → base64 data URI
- 移除全部代码注释
- 合成结果与原版逐字节一致（已用 Node 对比验证）
